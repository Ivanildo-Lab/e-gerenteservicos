================================================================================
RESUMO DO PROJETO
================================================================================

TIPO: Projeto Django
NOME: e-gerenteservicos
DESCRIÇÃO: Sistema de gerenciamento de serviços com módulos de:
           - Cadastro de clientes e fornecedores
           - Gestão financeira e contábil
           - Geração de relatórios
           - Autenticação de usuários
           - Configurações do sistema

APLICAÇÕES PRINCIPAIS:
1. cadastros  - Gerenciamento de pessoas (clientes, fornecedores)
2. core       - Configurações centrais do sistema
3. financeiro - Movimentações financeiras e contabilidade
4. web        - Interface web, autenticação e dashboard

ESTRUTURA DE ARQUIVOS:
- Padrão MVT Django (Models, Views, Templates)
- URLs organizadas por aplicação
- Forms para validação de dados
- Templates por aplicação
- Migrações por aplicação
- Admin Django configurado
